# Catkin privacy policy

The public privacy policy page for the Catkin mobile app, linked from its
Google Play listing and from inside the app. Everything is in `index.html`.

## Publish with GitHub Pages

1. Create a **public** repository on GitHub (e.g. `catkin-privacy-policy`) and push this folder to it.
2. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, branch `master` (or `main`), folder `/ (root)`, and save.
3. After a minute the page is live at `https://<your-github-username>.github.io/catkin-privacy-policy/`.
4. Paste that URL into Play Console → **App content → Privacy policy**.

## Updating

Edit `index.html`, change the effective date at the top, commit and push. GitHub Pages republishes it automatically.
